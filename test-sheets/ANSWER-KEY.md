# Answer key — what the three sheets should say

Read each line to Riaz **without telling him what it is meant to say**. Write
down what he reads, then compare. A line he cannot read at all is as useful a
result as one he reads wrongly — note which it was.

All three sheets are within 28 cells and fit A4. They are generated by
`tools/make_test_sheets.py`; if you change a line here, change it there too.

**One line to watch: line 11.** The last item, ڻھ, is written 3456 then 236.
Dots 3-4-5-6 at the start of a word are also the number sign, and 236 is also
the lower 8 — so the same two cells can be read as ⅛. In real Sindhi this never
arises, because no ordinary Sindhi word begins with ڻ, but on a bare letter list
it does.  ڻھ is one of only four spellings in the whole word list that this code
cannot read back, and this collision is exactly why. **If Riaz reads that item as a fraction, that is the code
behaving as printed, not a mistake in the file** — and it is worth asking him
how a reader is meant to tell the two apart.

## Sheet 3 — `print-3-poetry-maths-foreign.brf`  (verse, arithmetic, other languages)

The three areas that had never been checked. Nineteen lines.

| line | what it tests | should read |
|---|---|---|
| 1–4 | the guide's four sums | 8 + 9 = 17 · 20 − 13 = 7 · 12 × 8 = 96 · 91 ÷ 7 = 13 |
| 5 | fractions | 3/7 1/2 13/44 |
| 6 | decimal, thousands, ratio | 1.75 1,000 2:3 |
| 7 | per cent — the sign comes **before** the number | 50% 1% |
| 8 | round brackets in arithmetic (126, 345) | (8 + 9) = 17 |
| 9 | braces | {12 + 3} = 15 |
| 10 | Roman numerals | VIII IX X |
| 11 | one English word inside Sindhi | هي Thanks لفظ آهي. |
| 12–13 | two English words — one pair of marks around **both** | اسڪول جو نالو City School آهي. |
| 14–15 | capitals inside a longer English run | مان Computer Science پڙهان ٿو. |
| 16 | an Urdu word — same script, no marks needed | هن ۾ اردو لفظ کتاب آهي. |

**Line 16, and a decision that came out of it.** ک is one character to a computer but two letters to a linguist: 1-3 2-3-6 in Sindhi, 1-3 in Urdu. Reading this line Riaz Hussain Memon noticed it, and on 15 August 2026 ruled that it does not matter — Sindhi shares many letters with Urdu and a reader reads that letter the same way either way. The software writes the Sindhi value always and does not try to guess a word's language.

| 17–19 | a bait in verse marks, with the pen-name | سنڌ ڀٽائي جي ڀونءِ / هتي امن ۽ محبت آهي / لطيف چوي ٿو سچ |

**Line 3 is the one to watch.** The multiplication sign is dots 5-6 2-3-6 —
exactly the two cells that open a foreign word. Nothing in the cells themselves
tells them apart; only whether a word follows with no space. Ask Riaz how a
reader resolves it.

**Lines 17–19 are the first verse ever set in this code by software.** The marks
are 12356 twice at the start of the stanza, once more attached to the end of each
hemistich, a full stop at the end, and dot 2 immediately before لطيف. If any of
that is not how a Sindhi braille reader expects a bait to look, that is exactly
the finding worth having.

The same material to read on screen, with the dot numbers beside every line, is
